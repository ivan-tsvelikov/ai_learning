# Auth

Володіє обліковими записами, реєстрацією, логіном і правилами паролів.

Терміни: User — обліковий запис; Email — адреса входу; Password hash — збережений результат хешування.

- Публікує: UserRegistered.
- Слухає: жодних подій у поточній карті.
- Будова майбутнього коду: domain/app/infra; app -> domain, infra -> app/domain.
- JPA, HTTP, CDI та хешування через зовнішні засоби — в infra; domain без фреймворків. Прямі імпорти інших BC заборонені.

На етапі каркаса бізнес-коду немає. Джерело меж: docs/bc-map.md.
