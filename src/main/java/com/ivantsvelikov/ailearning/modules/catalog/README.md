# Catalog

Володіє товарами та категоріями. У навчальному демо каталог лише читається.

Терміни: Product — товар; Category — група товарів; Price — ціна у цілих minor units.

- Публікує: жодних подій у поточній карті.
- Слухає: жодних подій у поточній карті.
- Будова майбутнього коду: domain/app/infra; app -> domain, infra -> app/domain.
- JPA entities і REST — в infra, окремо від domain objects; прямих імпортів інших BC немає.

На етапі каркаса бізнес-коду немає. Джерело меж: docs/bc-map.md.
