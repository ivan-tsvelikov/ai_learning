# Commerce

Володіє оформленими замовленнями, їхніми позиціями, сумою та статусом. Окремої сутності Cart у демо немає.

Терміни: Order — замовлення; Order item — його позиція; Total — підсумкова сума; Status — стан замовлення.

- Публікує: OrderPlaced; слухають Billing і Notifications.
- Слухає: жодних подій у поточній карті.
- Будова майбутнього коду: domain/app/infra; app -> domain, infra -> app/domain.
- Правила замовлення — domain; сценарії й порти — app; REST/JPA/публікація подій — infra. Імпорти Catalog/Auth та інших BC заборонені.

На етапі каркаса бізнес-коду немає. Джерело меж: docs/bc-map.md.
